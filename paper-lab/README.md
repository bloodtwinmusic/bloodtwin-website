# £10 Paper Lab Odds Logger

Automated prospective odds collection for the blood.twin £10 Paper Lab.

Paper-only research. No real-money betting actions.

## Purpose

The logger records timestamped pre-event bookmaker prices so that the experiment can measure:

- price movement
- de-vigged market probabilities
- estimated edge
- entry-price timing
- closing-line value (CLV)
- model calibration

Historical observations are preserved rather than reconstructed after results are known.
